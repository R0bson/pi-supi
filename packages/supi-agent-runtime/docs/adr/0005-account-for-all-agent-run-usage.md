# Account for all Agent Run usage

Each Agent Run Outcome aggregates every PI Usage record billed inside its owned session: assistant turns, nested-model tool results, compaction, and branch-summary calls, preserving optional reasoning/cache and cost fields. The caller reports that Usage once through the foreground tool result or a stored background collection result, preventing delegation from reporting the same work twice. Background collection and its reporting limitations remain caller-owned; see [the Agent decision](../../../supi-agent/docs/adr/0010-own-background-delegation-in-the-containing-session.md).
